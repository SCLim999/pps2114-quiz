# 虚拟人生（Virtual Life）

一个纯前端的人生模拟小游戏：**中学毕业 → 升学 → 修课考试 → 就业或创业 → 人生结局**。
不需要服务器，打开 `game/index.html` 就能玩，进度存在浏览器的 localStorage 里。

## 画风

参考《模拟人生 4》(The Sims 4) 的 UI：淡蓝天空渐层背景、白色圆角玻璃面板、青绿主色、
胶囊状按钮，需求条（精力 / 健康 / 压力 / 幸福感）像游戏里的需求槽一样按数值由绿转黄转红。
角色名字旁边有一颗 **Plumbob**（头顶的绿色菱形水晶），颜色会跟着心情走 ——
心情好是绿的，压力大或健康差会变黄、变红。

字体走本地字体栈（装了 Nunito / Quicksand 会自动用上），**不外链任何资源**，离线也能玩。

## 怎么玩

1. **开局**：取名字，选一个**天赋**（学霸 / 社交达人 / 技术极客 / 生意头脑 / 铁人 / 好运）
   和一个**家庭背景**（富裕 / 小康 / 清寒）。天赋与家境会影响成长倍率、起始资金与每学期家用。
2. **升学**：会考成绩（由知识决定）决定你能走哪条路 —— 直接工作 / 技术学院（大专 2 年）/
   大学（本科 4 年）。选定后再挑**主修**：计算机、工程、商业管理、金融、医学、设计。
3. **求学**：每学期有 **4 个行动点**，可以上课、图书馆苦读、做项目、社团、兼职、
   争取实习、参加竞赛、搞副业、运动、休息。学期末**期末考**按「知识 × 课程考核能力 −
   课程难度 + 出席加分」评分，拿等级与绩点（GPA），修过的课还会加对应能力。
   - 挂科累计 **5 科会被退学**。
   - 学费不够会自动办**助学贷款**，工作后从年薪里扣。
4. **毕业路口**：可以**继续升学**（大专 → 专升本；本科 → 硕士）、**找工作**或**创业**。
5. **就业**：人才市场按你的**求职竞争力**（GPA、专业能力、实习、人脉、声望、学历）给 offer。
   每年 2 个行动：加班冲绩效、进修考证、拓展人脉、副业、投资、陪家人、跳槽、在职进修学位、
   辞职创业。绩效攒够就升职，一路可以爬到 CTO / CEO / 合伙人。
6. **创业**：投入 80% 存款成立公司。每年 2 个行动：打磨产品、招人、市场营销、亲自跑客户、
   对外融资（每轮稀释 25% 股份）、降本增效、休息。产品力与营销力带动**客户规模复利成长**，
   现金流连续两年撑不住就结业。**估值 ≥ 4 亿元且年营收 ≥ 6000 万元可以上市**。
7. **结局**：50 岁做人生总结，按财富、职位、声望、健康、幸福感与学历给评分和称号 ——
   从「商业传奇」「登顶高管」「一份不错的工作」到「平凡打工人」「负债人生」。
   **健康归零会直接终局**，别把身体熬完了。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 游戏页面 |
| `css/game.css` | 样式 |
| `js/data.js` | **内容与数值表** —— 天赋、家境、路线、专业课程、行动、随机事件、职业、创业动作 |
| `js/engine.js` | 游戏规则（纯逻辑，不碰 DOM，可用 node 单独跑模拟） |
| `js/ui.js` | 画面与点击处理 |

想改内容（加一个专业、加一门课、调整薪水或事件），只动 `js/data.js` 就够了。

## 平衡性怎么验证

`js/engine.js` 不依赖浏览器，所以可以让「机器人玩家」自动玩几千局来看结局分布。
把 `data.js` + `engine.js` 用 `vm` 载入同一个作用域，然后按阶段自动选行动即可
（一路读书的玩家 ≈ 45% 高薪精英 / 35% 一份不错的工作；专心创业的玩家约 30% 能做到上市，
摆烂的玩家大多是平凡打工人）。
